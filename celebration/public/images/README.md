# Images

Drop photographs here and point at them from `data/`:

- `data/days.ts` — `feature.image: "/images/25th.jpg"` on a main day
- `data/story.ts` — `image: "/images/1976.jpg"` on a timeline milestone
- `data/story.ts` — `src: "/images/gallery/wedding-01.jpg"` on a gallery item
- `data/spiritual.ts` — `speaker.image`
- `data/venues.ts` — `venueMapImage: "/images/venue-map.jpg"` for the real property plan

Until a file is supplied, each of those places renders a designed placeholder,
so the site never looks broken while you gather the photographs.

Keep files under about 400 KB — resize to 1600px on the long edge before adding.
